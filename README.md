# JAMIA NAGAR — ব্যবহার ও আপডেট নির্দেশিকা

## ফোল্ডার কাঠামো
```
jamia-nagar/
├── index.html          ← মূল পেজ (তিনটি পেজ এখানেই)
├── css/style.css       ← ডিজাইন ও রং (উপরের :root এ রং বদলানো যায়)
├── js/
│   ├── config.js       ← নাম, ইমেইল, লগইন কোড, WhatsApp নম্বর, লোগো/ব্যাকগ্রাউন্ড ছবির পথ
│   ├── contacts.js     ← আসাতিজা ও মুলাযিমদের নাম/নম্বর
│   ├── nigran.js       ← জামাত/বিভাগ অনুযায়ী নেগরান
│   ├── books.js        ← কিতাব ও লেখক
│   ├── history.js      ← ইতিহাস ও শিক্ষাধারা
│   ├── i18n.js         ← বাটন/শিরোনামের বাংলা-আরবি লেখা
│   └── app.js          ← কার্যক্রম (সাধারণত ছোঁবেন না)
└── assets/ (campus.jpg, logo.jpg, books/ ← কিতাবের কভার এখানে রাখুন)
```

## VS Code-এ চালানো
1. VS Code → File → Open Folder → `jamia-nagar` নির্বাচন করুন।
2. Extensions থেকে **Live Server** (Ritwick Dey) ইনস্টল করুন।
3. `index.html` এ ডান ক্লিক → **Open with Live Server**।
   (শুধু `index.html` ডাবল ক্লিক করলেও চলে; তবে নম্বর "কপি" বাটন নিরাপদ সংযোগে (Live Server/https) সবচেয়ে ভালো চলে।)
4. ফোনে দেখতে: কম্পিউটার ও ফোন একই Wi-Fi-তে রেখে ফোনে `http://কম্পিউটারের-IP:5500` খুলুন।
   অনলাইনে দিতে: ফোল্ডারটি Netlify / GitHub Pages / Cloudflare Pages-এ আপলোড করুন (ফ্রি)।

## তথ্য আপডেট
- **নতুন শিক্ষক:** `js/contacts.js` খুলে যে গ্রুপে চান সেখানে একটি লাইন কপি করে বদলান:
  `{ name: "নাম", role: "পদ", phone: "01XXXXXXXXX" },`
- **মুছতে:** লাইনটি মুছুন। **নম্বর সবসময় "কোটেশনের" ভেতরে** লিখুন (নইলে শুরুর ০ হারাবে)।
- **নেগরান:** `js/nigran.js` এ একইভাবে।
- **কিতাব:** `js/books.js` এ কিতাব যোগ করুন; কভার ছবি `assets/books/` এ রেখে `cover: "assets/books/নাম.jpg"` দিন; নমুনা কিতাব মুছে দিন।
- **WhatsApp নম্বর:** `js/config.js` → `whatsappNumber: "8801XXXXXXXXX"` (দেশের কোডসহ, + ছাড়া)।
- **লগইন কোড:** `js/config.js` → `accessCode`।
- **ইতিহাস:** `js/history.js` এর প্রতিটি লাইন একটি অনুচ্ছেদ — সম্পাদনা করুন।
- সেভ করে ব্রাউজার রিফ্রেশ করুন — সার্চ, কার্ড, সংখ্যা সব নিজে থেকে বদলাবে।

## জানা দরকার
- লগইন কোডটি শুধু একটি **সাধারণ গেট**; যে কেউ ব্রাউজারে কোড দেখে এটি জানতে পারে। সত্যিকারের নিরাপত্তার জন্য ভবিষ্যতে সার্ভার-সাইড লগইন দরকার।
- ফন্ট Google Fonts থেকে আসে (ইন্টারনেট লাগে); অফলাইনে সিস্টেম ফন্ট ব্যবহার হবে।
